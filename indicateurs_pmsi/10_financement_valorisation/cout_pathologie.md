# Coût par Pathologie

## Définition
Le coût par pathologie mesure le coût moyen de prise en charge pour une pathologie donnée, incluant les frais de séjour, les actes médicaux, et les examens complémentaires. Cet indicateur est essentiel pour le pilotage financier des GHT.

## Calcul
Le coût par pathologie est calculé comme suit :

```
Coût par pathologie = (Coût total des séjours pour la pathologie) / (Nombre de séjours pour la pathologie)
```

## Utilité
- **Optimisation des dépenses** : Identifier les pathologies les plus coûteuses pour cibler les économies.
- **Négociation tarifaire** : Données utilisées dans les négociations avec les ARS et l'Assurance Maladie.
- **Benchmarking** : Comparaison des coûts entre établissements ou GHT.

## Sources de Données
- **PMSI** : Données issues des RSS et des tarifs associés aux GHM (Groupes Homogènes de Malades).
- **ScanSanté** : Analyse des coûts par pathologie et par GHT.

## Exemple de Valeurs
- **Coût moyen d'une appendicectomie** : ~2 500 € (source : ATIH 2023).
- **Coût moyen d'une pneumonie** : ~4 000 € (variable selon la sévérité).

## Limites
- Ne prend pas en compte les coûts indirects (ex : réadmissions, complications).
- Peut varier selon les pratiques locales et les tarifs régionaux.
