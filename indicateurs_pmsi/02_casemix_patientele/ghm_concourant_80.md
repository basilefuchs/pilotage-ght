# Nombre de GHM Concourant à 80% des Séjours

## Définition
Le nombre de GHM concourant à 80% des séjours mesure la concentration de l'activité hospitalière sur un nombre restreint de groupes homogènes de malades (GHM). Cet indicateur, inspiré de la loi de Pareto, permet d'identifier les GHM dominants qui représentent la majorité de l'activité.

## Calcul
Le nombre de GHM concourant à 80% des séjours est calculé comme suit :

```
1. Classer les GHM par ordre décroissant de volume de séjours.
2. Cumuler les volumes jusqu'à atteindre 80% du total.
3. Compter le nombre de GHM nécessaires pour atteindre ce seuil.
```

## Utilité
- **Pilotage de l'activité** : Identifier les GHM prioritaires pour l'allocation des ressources.
- **Benchmarking** : Comparaison entre établissements ou GHT.
- **Optimisation** : Cibler les actions d'amélioration sur les GHM dominants.

## Sources de Données
- **PMSI MCO** : Données issues des RSS, incluant les GHM et volumes de séjours.

## Exemple de Valeurs
- **Nombre moyen de GHM** : 20-30 GHM pour 80% de l'activité (variable selon la taille de l'établissement).
- **Variation par spécialité** : Chirurgie (15-25 GHM), Médecine (25-35 GHM).

## Limites
- Ne reflète pas la complexité des GHM, seulement leur volume.
- Peut masquer des GHM rares mais stratégiques (ex : recours).
