# Taux d'Événements Indésirables Graves (EIG)

## Définition
Le taux d'événements indésirables graves (EIG) mesure la proportion de séjours au cours desquels un événement indésirable grave est survenu, tel que défini par la Haute Autorité de Santé (HAS). Ces événements incluent les erreurs médicamenteuses, les chutes, les infections nosocomiales graves, etc.

## Calcul
Le taux d'EIG est calculé comme suit :

```
Taux d'EIG (%) = (Nombre de séjours avec EIG / Nombre total de séjours) × 100
```

**Critères d'EIG** :
- Événements ayant entraîné un préjudice significatif pour le patient.
- Événements évitables (ex : erreur de médicament, chute avec fracture).

## Utilité
- **Sécurité des soins** : Identifier les risques et mettre en place des actions correctives.
- **Benchmarking** : Comparaison entre établissements ou services.
- **Culture de sécurité** : Sensibilisation des équipes aux risques.

## Sources de Données
- **PMSI** : Codes CIM-10 spécifiques pour les EIG.
- **Signalements obligatoires** : Données des commissions de sécurité des soins.
- **SNDS** : Données complémentaires sur les complications.

## Exemple de Valeurs
- **Taux national moyen** : 1-3% (variable selon les services).
- **Services à risque** : Réanimation (3-5%), Urgences (2-4%).
- **Objectif** : Réduction de 50% des EIG évitables.

## Limites
- Sous-déclaration possible (biais de notification).
- Dépend de la définition des EIG (variabilité inter-établissements).
