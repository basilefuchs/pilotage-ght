# Taux de Séjours avec Erreurs de Codage

## Définition
Le taux de séjours avec erreurs de codage mesure la proportion de séjours présentant des erreurs dans le codage des diagnostics, des actes, ou des autres éléments du Résumé de Sortie Standardisé (RSS). Cet indicateur évalue la qualité du codage et son impact sur la tarification et les analyses.

## Calcul
Le taux d'erreurs de codage est calculé comme suit :

```
Taux d'erreurs de codage (%) = (Nombre de séjours avec ≥ 1 erreur de codage / Nombre total de séjours) × 100
```

**Types d'erreurs** :
- Erreurs de diagnostics (CIM-10).
- Erreurs d'actes (CCAM).
- Erreurs de groupage (GHM).

## Utilité
- **Qualité du codage** : Identifier les erreurs et former les équipes.
- **Optimisation financière** : Réduire les pertes liées aux erreurs.
- **Benchmarking** : Comparaison entre établissements ou GHT.

## Sources de Données
- **PMSI** : Données issues des RSS.
- **OVALIDE** : Outil de validation des données PMSI (ATIH).
- **Audits internes** : Contrôles qualité.

## Exemple de Valeurs
- **Taux national moyen** : 5-10%.
- **Seuil d'alerte** : > 15% (nécessite une action corrective).

## Limites
- Dépend des outils de détection des erreurs.
- Peut varier selon les pratiques de codage.
