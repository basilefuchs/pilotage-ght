# Nombre de Séjours

## Définition
Le nombre de séjours mesure le volume total d'hospitalisations dans un établissement ou un GHT sur une période donnée. Cet indicateur est fondamental pour évaluer l'activité globale et la charge de travail.

## Calcul
Le nombre de séjours est calculé comme suit :

```
Nombre de séjours = Somme des hospitalisations (tous types confondus)
```

## Utilité
- **Mesure de l'activité** : Indicateurs clé pour le suivi de l'activité hospitalière.
- **Planification des ressources** : Aide à dimensionner les besoins en personnel et en équipements.
- **Benchmarking** : Comparaison entre établissements ou GHT pour identifier les tendances.

## Sources de Données
- **PMSI** : Données issues des Résumés de Sortie Standardisés (RSS).
- **ScanSanté** : Analyse des séjours par GHT, service ou pathologie.

## Exemple de Valeurs
- **Nombre annuel de séjours (MCO)** : Variable selon la taille de l'établissement (ex : 10 000 à 100 000).
- **Répartition par service** : Médecine (40%), Chirurgie (30%), Obstétrique (15%), etc.

## Limites
- Ne distingue pas les séjours courts des longs séjours.
- Peut être influencé par des facteurs saisonniers ou épidémiques.
