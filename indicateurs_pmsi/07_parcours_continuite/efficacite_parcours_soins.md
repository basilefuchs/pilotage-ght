# Efficacité des Parcours de Soins

## Définition
L'efficacité des parcours de soins mesure la capacité d'un établissement ou d'un GHT à assurer une prise en charge coordonnée et sans rupture pour les patients. Cet indicateur évalue la fluidité et la qualité de la coordination entre les différents acteurs et services.

## Calcul
L'efficacité des parcours de soins peut être mesurée via plusieurs sous-indicateurs :

```
1. Délai moyen entre les étapes clés du parcours (ex : diagnostic → traitement).
2. Taux de conformité aux protocoles de parcours (ex : respect des référentiels).
3. Taux de patients perdus de vue ou sans suivi post-hospitalisation.
```

## Utilité
- **Amélioration de la qualité** : Identifier les ruptures dans les parcours pour les corriger.
- **Coordination territoriale** : Renforcer la collaboration entre établissements d'un GHT.
- **Optimisation des coûts** : Réduire les redondances et les inefficacités dans les parcours.

## Sources de Données
- **PMSI** : Suivi des parcours via les RSS et les chaînages de séjours.
- **Dossiers Patients Informatiques (DPI)** : Données de coordination entre services.
- **Enquêtes de parcours** : Retours patients et professionnels.

## Exemple de Valeurs
- **Délai moyen diagnostic-traitement (cancer)** : < 30 jours (objectif national).
- **Taux de conformité aux protocoles** : > 90% pour les parcours prioritaires.

## Limites
- Mesure complexe nécessitant des données multi-sources.
- Peut varier selon les pathologies et les territoires.
