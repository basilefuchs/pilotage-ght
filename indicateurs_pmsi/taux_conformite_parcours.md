# Taux de Conformité aux Parcours de Soins

## Définition
Le taux de conformité aux parcours de soins mesure la proportion de séjours conformes aux parcours types définis par les référentiels de bonnes pratiques (ex : parcours cancérologie, parcours AVC). Cet indicateur évalue la qualité de l'organisation des soins et le respect des recommandations.

## Calcul
Le taux de conformité aux parcours de soins est calculé comme suit :

```
Taux de conformité (%) = (Nombre de séjours conformes au parcours type / Nombre total de séjours pour le parcours) × 100
```

**Critères de conformité** :
- Respect des étapes clés (ex : délais, examens, consultations).
- Coordination entre acteurs (ville, hôpital, SSR).

## Utilité
- **Qualité des soins** : Évaluer l'adhésion aux bonnes pratiques.
- **Coordination** : Identifier les ruptures dans les parcours.
- **Amélioration continue** : Cibler les étapes à optimiser.

## Sources de Données
- **PMSI** : Chaînage des séjours pour suivre les parcours.
- **Référentiels** : Parcours types (HAS, INCa, etc.).

## Exemple de Valeurs
- **Parcours cancérologie** : Taux de conformité = 70-85%.
- **Parcours AVC** : Taux de conformité = 60-80%.
- **Objectif** : Amélioration de 10% par an.

## Limites
- Dépend de la définition des parcours types.
- Nécessite un chaînage robuste des séjours.
