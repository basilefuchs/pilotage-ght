# Taux de Parcours Optimisés

## Définition
Le taux de parcours optimisés mesure la proportion de parcours de soins respectant les délais et étapes clés définis par les référentiels (ex : délai diagnostic-traitement, coordination entre acteurs). Cet indicateur évalue l'efficacité de l'organisation des soins et la fluidité des parcours.

## Calcul
Le taux de parcours optimisés est calculé comme suit :

```
Taux de parcours optimisés (%) = (Nombre de parcours respectant les critères d'optimisation / Nombre total de parcours) × 100
```

**Critères d'optimisation** :
- Respect des délais (ex : < 30 jours pour un parcours cancérologie).
- Coordination entre acteurs (ville, hôpital, SSR).
- Absence de rupture dans le parcours.

## Utilité
- **Qualité des soins** : Évaluer l'efficacité des parcours.
- **Coordination** : Identifier les goulots d'étranglement.
- **Amélioration continue** : Optimiser les étapes critiques.

## Sources de Données
- **PMSI** : Chaînage des séjours pour suivre les parcours.
- **Référentiels** : Critères d'optimisation (HAS, INCa).

## Exemple de Valeurs
- **Parcours cancérologie** : Taux d'optimisation = 60-80%.
- **Parcours AVC** : Taux d'optimisation = 50-70%.
- **Objectif** : Amélioration de 10% par an.

## Limites
- Dépend de la définition des critères d'optimisation.
- Nécessite un chaînage robuste des séjours.
