# Délai d'Attente

## Définition
Le délai d'attente mesure le temps moyen entre la demande de consultation ou d'hospitalisation et la réalisation effective de l'acte. Cet indicateur est crucial pour évaluer l'accessibilité aux soins et la satisfaction des patients.

## Calcul
Le délai d'attente est calculé comme suit :

```
Délai d'attente (jours) = (Date de réalisation - Date de demande) / Nombre de demandes
```

## Utilité
- **Accessibilité aux soins** : Identifier les goulots d'étranglement dans l'accès aux soins.
- **Planification des ressources** : Ajustement des capacités pour réduire les délais.
- **Satisfaction patient** : Un délai court améliore l'expérience patient.

## Sources de Données
- **Logiciels de rendez-vous** : Données issues des systèmes de gestion des rendez-vous.
- **PMSI** : Pour les hospitalisations programmées.
- **Enquêtes patients** : Retours subjectifs sur les délais perçus.

## Exemple de Valeurs
- **Délai moyen pour une consultation spécialisée** : 30-60 jours (variable selon les spécialités).
- **Délai moyen pour une hospitalisation programmée** : 15-45 jours.

## Limites
- Peut varier selon l'urgence et la spécialité.
- Ne prend pas en compte les annulations ou reports.
